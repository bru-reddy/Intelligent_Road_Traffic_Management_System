# Reconstruction Evidence Notes

The source documentation used for this reconstruction identifies:
- React/Vite frontend and FastAPI backend.
- JWT/bcrypt authentication and four roles: Commoner, Operator, Admin, Commissioner.
- Live traffic monitoring and congestion tracking.
- Random Forest prediction with fallback heuristic.
- TomTom search, traffic and routing integration.
- Route alternatives and travel-time estimation.
- Alerts, alert lifecycle, congestion heatmaps, traffic trends and road-performance analytics.
- Docker/cloud deployment as a goal, while Milestone 4 records Docker/containerization as pending.

Original trained model/dataset and exact original source are not included in the supplied documentation, so the ML implementation in this repository is reproducible rather than a recovered copy of the lost trained artifact.
